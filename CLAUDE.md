# CLAUDE.md — Engineering Paper Writing (Claude Code Bootstrap)

@WORKFLOW.md

## Quick Start
1. Start with **Phase 0: Research Intake and Source Review**
2. Ask the user to select one or more input modes: Notion link, PPT/PDF upload, local document, direct chat input, or multi-source
3. Record sources in `knowledge/source_manifest.md` and present an integrated summary for user review
4. Only after explicit summary approval, fill in the **Research Configuration** block in `WORKFLOW.md`
5. Set `Journal Family: IEEE` or `Journal Family: Elsevier`
6. Create and obtain approval for `drafts/draft_plan.md`
7. Follow Phase 1 → Phase 8 sequentially
8. Do NOT skip verification gates

## Key Paths
- `method/`        — Mathematical derivations, proofs, notation.md
- `simulation/`    — MATLAB / Python simulation code and results
- `experiment/`    — Experimental data and analysis
- `comparison/`    — Baseline comparisons (CSV)
- `drafts/`        — LaTeX source files
- `review/gates/`  — Gate verification reports
- `output/`        — Final PDF and submission package

## STOP Signals
If any gate fails → STOP. Fix before proceeding.
