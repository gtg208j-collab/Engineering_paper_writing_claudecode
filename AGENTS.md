# AGENTS.md — Engineering Paper Writing (Codex / Agent Bootstrap)

See WORKFLOW.md for the full engineering paper writing workflow.

## Agent Guidelines
- Always read WORKFLOW.md completely before starting any task
- Set Journal Family (IEEE or Elsevier) before any writing
- Never skip verification gates (Sections: Critical Rules → Rule 9)
- Notation consistency: all symbols must appear in method/notation.md
- Claims must be traceable to comparison/baseline_*.csv

## File Conventions
- LaTeX source: drafts/<journal_abbrev>_draft.tex
- References: drafts/references.bib (run format_references.py before submission)
- Gate reports: review/gates/<gate_name>_PASS.md or _FAIL.md
